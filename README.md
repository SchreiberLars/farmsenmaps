# Farmsen-Maps

Interaktive Stadtteil-Karte von Hamburg Farmsen-Berne: Orte nach Themen (Gesundheit, Einkaufen, Sport, Familie, Natur, Mobilität und mehr), Filter "jetzt geöffnet", 3D-Gebäude, Satellit, Topografie und Höhenschichten.

Live: https://schreiberlars.github.io/farmsenmaps/

## Datenquellen
- Orte und Stadtteilgrenze: © OpenStreetMap-Mitwirkende (ODbL), live über die Overpass API
- Basiskarte: OpenFreeMap
- Satellit: Esri World Imagery
- Topografie: OpenTopoMap
- Höhendaten: Mapzen Terrarium (AWS Terrain Tiles)
